# 📊 Marketing Campaign Performance Analysis

## 📌 Project Overview

This project analyzes marketing campaign performance using Microsoft Power BI.

The dashboard is designed to monitor campaign efficiency across marketing channels, track acquisition costs, analyze user engagement, and identify high-performing audience segments.

The goal is to transform campaign-level data into actionable business insights through interactive dashboards and DAX-based KPIs.

## 🎯 Business Objectives

The project aims to answer the following business questions:

- How much are we spending on marketing campaigns?
- Which channels generate the most clicks?
- Which channels have the lowest Cost Per Click (CPC)?
- How many impressions are generated across campaigns?
- Which campaign types receive the highest investment?
- Which age groups show the strongest engagement?
- How does marketing spend change over time?
- Which campaigns and channels perform most efficiently?
- What are the key opportunities for improving campaign efficiency?

## 📈 Key Metrics

### Total Spend

Total acquisition cost across marketing campaigns.

### Total Impressions

Total number of campaign impressions.

### Total Clicks

Total number of clicks generated by campaigns.

### CPC

Cost Per Click measures the average acquisition cost for each click.

### Average Campaign Duration

Average number of days campaigns remain active.
